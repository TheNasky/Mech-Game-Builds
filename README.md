# Mech game playtest builds

Built game files for the Mech game playtest launcher. No source code lives here.

- `latest.json`: the newest build (version, notes, server address, file and checksum). The launcher reads it on every start.
- `builds/<version>/game.pck`: the game itself, the five newest builds.
- The launcher kit (`MechGame-Launcher.zip`) is under Releases: unzip it and run `MechGame.exe`.
